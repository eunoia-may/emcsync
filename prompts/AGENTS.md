# AGENTS.md
## 施工流程
1. 阅读此文件的 `## 该做什么` 部分和项目本身的提交历史，了解基础事宜，随后按需阅读此目录除本文件和 `长期待办.md` 外的其余文档，获取空缺知识，非必要的文档可不读，避免占用上下文。

2. 了解情况后开始施工，施工事宜保持遵循根目录的 `AGENTS.md`。修改 README 与代码等非 AGENTS.md 和此目录文件的环节，都在此流程。

3. 完成此文件记录的 `## 该做什么` 中的任务后，修改那个部分，删去已经解决的，保留未解决的，全部解决则全部删去。

4. 阅读 `长期待办.md`，删去已完成的。

5. 确认无敏感内容后，敲定提交内容，让用户审阅，通过后提交。
