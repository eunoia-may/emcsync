# 命令设计与简单演示

## 输出约定
命令输出与提示应有跟随终端配色的彩色，且该用颜色实现醒目或区分度的地方才用颜色，不滥用，遇到不支持色彩的环境自动回退。

有 i18n 支持，检测用户语言环境实现输出不同语言的提示。

## 命令设计
```text
emcsync sync <source_dir> <target_dir> --version <mc_version> --loader <loader> --prefer <platform> [--jobs <jobs>] [--yes] [--dry-run]
emcsync help
```

大小写与拼写的纠错见 `执行流-sync-人性化纠错.md`。

## 参数说明
- `help` 帮助信息；此处写 `-h` 或 `--help` 同样可输出帮助

- `sync` 同步

- `<source_dir>` 提取源，即原实例的目录，若有空格需使用引号包裹（"" 或 ''）

- `<target_dir>` 复现目标，即待复现实例的目录，若有空格需使用引号包裹

- `-v, --version` 指定要复现的资源属于哪个 Minecraft 版本

- `<mc_version>` 填写版本，例如 `26.3`；版本列表不硬编码，从上游获取

- `-l, --loader` 指定加载器

- `<loader>` 填写加载器，目前支持 `fabric` `forge` `neoforge` `quilt`；硬编码，因为主流的极少，需要更多的话后续再添加

- `-p, --prefer` 指定优先从哪个平台获取资源

- `<platform>` 填写平台，目前支持 `modrinth` `curseforge`；硬编码

- `-j, --jobs` 指定同时下载的文件数

- `<jobs>` 填写 1-16 的整数，默认 4

- `-y, --yes` 预同意，跳过询问环节

- `-d, --dry-run` 只展示变化，不实际安装

## 使用示例
仅作为概念演示，不代表实际落地时的样子。

```shell
emcsync sync ~/.minecraft/versions/Tech_26.3-Fabric ~/.minecraft/versions/Tech_1.21.1-Fabric -v 1.21.1 -l fabric -p modrinth

/ 解析并匹配资源

下列资源将被安装
  sodium (mod) (modrinth)
  vybix (mod) (curseforge)
  xk-redstone-display (resourcepack) (modrinth)

下列资源在此版本不存在，故不安装
  wikirenderer (mod)

下列资源已存在于此实例，不再安装
  sodium-extra (mod)

下列资源无法在资源平台匹配，忽略
  sjaks.jar
  noto-font.zip

资源包目录尚不存在，确认后一并创建
确定安装吗？(Y/n):
```

将被安装的资源的格式是这样的：<slug> (<资源类型，mod/resourcepack/shaderpack>) (<平台>)。

不安装的、已被安装的，则不显示平台（不然又得反查一次）。

确认前若目标缺少 `mods/`、`resourcepacks/`、`shaderpacks/`，在同一个确认提示里写明将一并创建；`--dry-run` 只提示、不创建。

无法匹配的，直接显示那个文件的文件名。

优先在指定的偏好平台中查询，没查询到则去非偏好平台查询，返回结果按照首字母正向排序。

若选择继续或有 `-y` 参数，则开始下载并展示下载进度条（目前 rust 生态有库可以做到纯粹且现代的终端下载进度条）。

成功后提示`资源复现完毕！`，失败则提示`资源复现失败，可查看报错获取原因：`并在下方输出报错信息。
